## 🏠 Airbnb Data Analysis & Visualization – Tableau

## 📊 Project Overview

This project focuses on analyzing Airbnb listing data and creating interactive visualizations using **Tableau**.

The goal of this project is to understand Airbnb pricing patterns, customer reviews, property characteristics, ratings, and regional trends through data visualization.

The analysis helps identify differences in average prices, ratings, bed availability, and Airbnb activity across different locations and years.

## 🛠️ Tools & Technologies

* **Tableau** – Data visualization and dashboard development
* **CSV / Excel** – Dataset
* **Data Analysis** – Exploratory analysis and visualization

## 📁 Dataset

The dataset contains Airbnb listing information including:

* Host ID
* Host Since
* Property Name
* Neighbourhood
* Property Type
* Room Type
* Zipcode
* Number of Beds
* Number of Reviews
* Price
* Review Score Rating

The dataset contains approximately **3,000 Airbnb listings**.

## 📈 Key Visualizations

The Tableau workbook includes analysis such as:

### 1. Average Prices by Zipcode

Analyzes the average Airbnb price across different zip codes to identify variations in pricing by location.

### 2. Average Prices by Year

Examines how average Airbnb prices change over time.

### 3. Bed Availability by Top Regions

Compares the number of available beds across leading regions.

### 4. Top Regions by Ratings

Analyzes Airbnb ratings across different regions to identify highly rated locations.
